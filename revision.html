Deep Dive: Questions & Answers
Chapter 1
1. Write a CSS rule to set a paragraph font to Arial, text-align to center, and color to blue.
p {
  font-family: arial;
  text-align: center;
  color: blue;
}
2. Write the HTML5 code to embed an audio file named "test.mp3" with controls.
<audio controls>
  <source src="test.mp3" type="audio/mp3">
</audio>
Chapter 2
3. Define Search Engine Optimization (SEO).
SEO is the process of boosting content and technical set-up of the website so that it appears at the top of a search engine result for specific keywords, driving organic traffic.
4. Explain Technical SEO.
Technical SEO ensures the website meets technical requirements of search engines, like fast page load speed and mobile friendliness. Slow or unresponsive sites are ranked lower.
Chapter 4
5. Define E-Commerce.
E-Commerce is broadly defined as the process of buying and selling of goods or services using an electronic medium such as the Internet, acting as a paperless exchange.
6. What is a Digital Signature?
A digital signature guarantees the authenticity of an electronic document in digital communication, using asymmetric cryptography to prove the document is unmodified.
