<head>

    </ul>
  </div>
</body>
</html>

Q.7 Answer the Following (Any 5) [10 Marks]

1. What is the use of the <meta> tag in HTML5?
Ans: The <meta> tag is an empty tag placed in the <head> section. It describes aspects of the webpage's contents, providing metadata like the author, description, keywords, and character encoding, which are heavily used by search engines.
2. Explain any two types of CSS styling methods.
Ans: 1) Inline CSS: Applied directly within a single HTML tag using the style attribute. 2) Internal/Embedded CSS: Placed inside the <style> tag in the head section to format a single document.
3. List any four advanced <input> elements introduced in HTML5.
Ans: Four advanced input elements are: color, date, email, and number.
4. How is a client-side image map created? Mention the tags used.
Ans: A client-side image map is created by using the <map> and <area> tags along with an <img> tag. The img tag uses the 'usemap' attribute to point to the name of the map, and the area tag defines clickable hotspots using shape and coords.
5. What is the difference between an ordered list and an unordered list?
Ans: An ordered list uses the <ol> tag and numbers its items sequentially (1, 2, 3 or a, b, c). An unordered list uses the <ul> tag and marks its items with bullets (circles, squares, discs).
6. Explain the purpose of the <iframe> tag.
Ans: The <iframe> tag is used to create an inline frame. It is heavily used to embed another HTML document, video, or online advertisement seamlessly inside the current webpage.
7. Name the three positioning properties available in CSS.
Ans: The main positioning properties in CSS are Static (default), Fixed (stays relative to the browser window), Relative (relative to its normal position), and Absolute (relative to screen/parent top-left corner).
